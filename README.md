# Article data explorer

Interactive companion to **Dark Matter Halo Formation with Enhanced Small-Scale Primordial Power**.

Open the site: [Article data explorer](https://hainahuang729.github.io/nonlinear-evolution-of-cosmological-structures-with-enhanced-primordial-power-spectrum/)

This branch contains the static GitHub Pages site. The manuscript remains on `main`.
No build step, external fonts, CDN, or application server is needed.

- Matched PL / BT kp=1 / BT kp=10 density projections at z=8.52, 2.03, and 0.
- Halo mass functions, nonlinear matter power spectra, assembly histories, and internal structure.
- CSV downloads and original article figures.
- Original projection panels retain independent color normalization; missing redshifts are explicitly marked.

Numerical source metadata, checksums, and display derivations are recorded in `data/provenance.json`.
The HMF ratio panel uses explicit common bins from the article's compact per-halo catalogs.
The Chinese font subset is distributed under the license in `assets/FONT-LICENSE.txt`.
